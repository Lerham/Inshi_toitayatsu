% 番号は章・節から独立した通し番号とし、元の位置には相互リンクだけを残す。
\newcounter{studyhint}
\newcounter{studyanswer}
\ExplSyntaxOn
\seq_new:N \g_study_hint_seq
\seq_new:N \g_study_answer_seq

\cs_new_protected:Npn \study_source_link:nn #1#2
  {
    \phantomsection
    \label{study-#1-origin-#2}
    \par\smallskip\noindent
    \hyperref[study-#1-#2]
      {\textit{\str_case:nn {#1} {{hint}{Hint}{answer}{Answer}}~#2
      （p.~\pageref*{study-#1-#2}）}}
    \par\smallskip
  }

\cs_new_protected:Npn \study_print_entry:nn #1#2
  {
    \par\medskip
    \phantomsection
    \label{study-#1-#2}
    \noindent\textbf{
      \str_case:nn {#1} {{hint}{Hint}{answer}{Answer}}~#2.}
    \quad
    \hyperref[study-#1-origin-#2]
      {\textit{元の掲載位置：p.~\pageref*{study-#1-origin-#2}}}
    \par\smallskip
    \tl_use:c {g_study_#1_#2_tl}
  }

\NewDocumentEnvironment{hint}{+b}
  {
    \refstepcounter{studyhint}
    \tl_gset:cn {g_study_hint_\arabic{studyhint}_tl} {#1}
    \seq_gput_right:Nx \g_study_hint_seq {\arabic{studyhint}}
    \study_source_link:nn {hint}{\arabic{studyhint}}
  }
  {}

\NewDocumentEnvironment{probans}{+b}
  {
    \refstepcounter{studyanswer}
    \tl_gset:cn {g_study_answer_\arabic{studyanswer}_tl} {#1}
    \seq_gput_right:Nx \g_study_answer_seq {\arabic{studyanswer}}
    \study_source_link:nn {answer}{\arabic{studyanswer}}
  }
  {}

\NewDocumentCommand{\printstudyhintsandanswers}{m}
  {
    \chapter{#1のHint・Answer}
    \seq_if_empty:NF \g_study_hint_seq
      {
        \section{Hints}
        \seq_map_inline:Nn \g_study_hint_seq
          {\study_print_entry:nn {hint}{##1}}
      }
    \seq_if_empty:NF \g_study_answer_seq
      {
        \section{Answers}
        \seq_map_inline:Nn \g_study_answer_seq
          {\study_print_entry:nn {answer}{##1}}
      }
    \seq_gclear:N \g_study_hint_seq
    \seq_gclear:N \g_study_answer_seq
  }

\subsection*{本書の性格と注意}
本書は, 執筆者個人の学習と院試対策のために作成した, かなり個人的なノートです。記述には, 内容の重要度, 難易度, 理解の仕方, 学習方法などに関する個人の感想や判断が多く含まれています。大学・研究科・教員などによる公式な資料ではありません。また, 数学的内容の正確性を保証するものでもありません。必要に応じて, 教科書・講義資料・過去問の公式資料なども確認してください。

\subsection*{編集について}
本書は, 執筆者が学部4回生(B4)であった2021年頃に作成していた原稿をもとに, AIを用いて構成・表現・文体などを大幅に編集したものです。とくに文体にはAIによる修正が多く含まれているため, 元の原稿や執筆者の意図よりも断定的なニュアンスを帯びている可能性があります。また, AIによる編集は数学的内容の正確性を保証するものではありません。必要に応じて原典も確認してください。

\subsection{院試対策ゼミについて}
院試問題に真剣に取り組み, さまざまな問題を解いたり議論したりします。これまでの講義で扱った問題や教科書から有用な内容を引用しながら, 院試対策ノートを兼ねた議事録を作成します。
活動時間は毎週土曜日13時から18時までです。メンバーは次の通りです。
\ben
\item Lim(主催者, 4回生)
\item ふじおか(4回生)
\item Seeker(4回生)
\item 似顔絵師(4回生)
\item Shakayami(M1)
\een
メンバーは作問サークル内で募集しました。将来は, このノートをサークル内で引き継いでもらえればと考えています。

\subsection{このノートについて}
院試対策を進める中で見つかった復習事項をまとめる目的で作成しました。本文は主にLiが執筆し, ゼミのメンバーからも問題を募集しました。

基本的には, 京都大学理学部の数理科学系で履修できる講義に対応する分野を扱っています。各sectionでは, はじめにsubsection「基礎事項」を置き, subsubsectionごとに基本事項を整理しています。発展度に応じて$\spadesuit$印を付しました。講義内容に直接対応する項目には印を付けず, 講義で扱われる場合と扱われない場合がある項目には$\spadesuit$を一つ, 学部生にはやや発展的と思われる項目には$\spadesuit\spadesuit$を付しています。
各sectionには演習問題のページを一つ用意しています。可能な限り解答も掲載しますが, 参考資料へのリンクのみを示す場合もあります。演習問題はLevel A, Level B, Level Cに分類しました。難易度の分類は執筆者の判断によるものであり, Level Aは基本的な問題, Level Cは相応の習熟を要する問題を表します。

演習問題のほかにも, 多くの例と例題を掲載しました。また, 簡単な思考練習のための\tf{練習問題}も配置しています。練習問題には解答を付していないため, 実際に手を動かして取り組んでみてください。

重要な定理は明記していますが, 証明を省略している場合もあります。
