# Inshi_toitayatsu

大学院入試の数学に関する、次の二つのTeX文書を管理するリポジトリです。

1. 手書き答案を文字起こしした「大学院数学院試 答案集」
2. 学部4回生の頃に作成した原稿をもとにした「院試対策ノート」

## 重要な注意

「院試対策ノート」は、執筆者個人の学習・院試対策のために作成した、かなり個人的なノートです。記述には、内容の重要度、難易度、理解の仕方、学習方法などに関する個人の感想や判断が多く含まれています。

- このノートは、執筆者(Lim_Rim_など)が学部4回生であった2021年頃の原稿をもとに、AIを利用して構成・表現・文体などを大幅に編集したものです。とくに文章はAIによる修正を多く含むため、元の意図より断定的に見える場合があります。数学的内容の正確性も保証されません。学習や受験の参考にする場合は、教科書・講義資料・過去問の公式資料なども確認してください。

「答案集」は、原答案の内容をできるだけ忠実に転記する方針です。そのため、原答案に含まれる誤りや不完全な記述を、そのまま収録している場合があります。明白な誤りを見つけた場合は本文を無断で補正せず、赤字と「ChatGPTによるfootnote」で注記します。

## リポジトリ構成

```text
.
├── tex/                       # 過去問答案集
│   ├── main.tex               # 答案集全体の入口
│   ├── preamble.tex
│   └── <大学>/<年度>/<問題>/
│       ├── answer-body.tex
│       ├── metadata.yml
│       └── source-images/
├── Inshi_Taisaku_Note/        # 院試対策ノート
│   ├── exam.tex               # ノート全体の入口
│   └── latexmkrc
├── docs/                      # 転記・公開方針など
└── output/pdf/                # 公開用PDF
```

答案集は、大学、年度、試験・問題の順に分類しています。各 `answer-body.tex` は単独の文書ではなく、`tex/main.tex` から読み込む本文断片です。照合用の原画像は、各答案の `source-images/` に保存しています。

## ビルド

### 大学院数学院試 答案集

```powershell
Set-Location tex
uplatex main.tex
uplatex main.tex
dvipdfmx main.dvi
```

公開用PDFは `output/pdf/大学院数学院試_答案集.pdf` です。

### 院試対策ノート

```powershell
Set-Location Inshi_Taisaku_Note
latexmk exam.tex
```

公開用PDFは `output/pdf/院試対策ノート.pdf` です。ビルド時にはSyncTeXも生成されるため、対応するビューアではPDFとTeXソースの間を移動できます。

## 転記と注記の方針

- 数式、文章、論証順序は、原則として原答案のまま転記します。
- 明白な誤りは本文を置き換えず、赤字と脚注で示します。
- 判読できない箇所を推測で補いません。
- AIが補ったHintなどには `(generated by ChatGPT)` を付けます。
- 詳細は `docs/transcription-policy.md` を参照してください。
