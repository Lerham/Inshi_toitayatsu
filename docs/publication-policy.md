# 公開リポジトリに含めるもの

## 公開する

- 文字起こししたTeX
- 共通TeXマクロ
- 大学、年度、試験名などの非個人的なメタデータ
- 答案ごとに選別し、不要な個人メタデータを確認した原画像 (`source-images/`)
- 文字起こし・注記方針
- 全答案を1冊にまとめた公開用PDF (`output/pdf/大学院数学院試_答案集.pdf`)

## 公開しない

- NotionのHTMLエクスポート一式
- 未整理の元画像および元PDF
- NotionページID、ワークスペース情報、内部パス
- メールアドレス、認証情報、環境変数ファイル
- 位置情報、撮影端末、氏名などの不要なメタデータを保持した画像
- TeXの中間生成物とローカルキャッシュ

元資料は照合用としてローカルには保存するが、`.gitignore` でGitの対象外にする。

## 公開前の確認

```powershell
git status --short --ignored
git ls-files
```

すでに追跡済みのファイルには `.gitignore` が効かない。その場合は、内容を確認したうえで追跡対象から外す必要がある。
